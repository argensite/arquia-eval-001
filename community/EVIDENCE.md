# External contribution evidence

The versioned [index](evidence-index.json) preserves provenance and uncertainty.
Categories are evidence types, not ranks or automatic progress stages:

| Category | Evidence represented |
| --- | --- |
| INVITATION | A request to participate; no execution implied |
| CLAIMED_RUN | A participant declares execution; artifacts/independence may be missing |
| REPRODUCIBLE_RUN | Exact artifact, commands, environment, outputs and exits allow checked reproduction; identify who reproduced it |
| INDEPENDENT_IMPLEMENTATION | Separately written code with source/provenance; not automatically an independent evaluator |
| COUNTEREXAMPLE | An identified falsifier with its hypothesis and reproducible trace |
| INCONCLUSIVE | Evidence does not settle the specified claim |
| CONTRACT_CRITIQUE | A challenge to assumptions or interpretation; execution not required |
| FORMAL_REVIEW | An actual identified review process, scope and externally controlled report |

The Gepetto-tipiak report is a public claimed run and critique. This project
reproduced the two instrument findings; that does not verify that party's run,
operator identity or independence. No verified external execution or formal
review is manufactured from that reproduction. Keep links, dates, hashes and
missing evidence. Third-party text remains under its own rights. Publish your
criticism under your control; affiliation and favorable results are never required.
