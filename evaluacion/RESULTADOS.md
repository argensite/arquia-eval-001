El registro identifica quién ejecutó y quién aportó al diseño. Cada informe mantiene su estado y procedencia. A report can involve external design input, a project run, an external reported run, or an externally verifiable reproduction. An independently held artifact and an independent evaluator are separate evidentiary questions. Record parties' declared relationships without inferring identity or independence.

| Clase / Type | Evidencia / Evidence |
| --- | --- |
| Corrida del proyecto / Project run | El proyecto ejecutó fuente o paquete identificable y conserva las salidas. The project ran the material and preserves outputs. |
| Aporte externo al diseño / External design contribution | Una crítica, hipótesis, escenario o criterio de fallo externo queda vinculado a su fuente. Execution need not be part of the contribution. |
| Corrida externa reportada / External reported run | El participante dice haber corrido el material y describe los resultados. Record which raw artifacts, commands and details were supplied and which are missing. |
| Reproducción externa verificable / Verifiable external reproduction | Un tercero publica la versión exacta, comandos, entorno, salidas y códigos contrastables de una nueva corrida. The reproduction can be checked against externally controlled artifacts. Record any corroboration and missing identity evidence separately. |

## Brennan Zambo · Historia y cronología / History and chronology

- **Diseño externo.** Brennan Zambo, quien declara trabajar en AER-1, propuso distinguir el estado al decidir, la llegada del recibo y la verificación. También propuso detectar una cronología reconstruida usando únicamente compromisos del publicador. [Contraejemplo original](https://github.com/a2aproject/A2A/discussions/2434#discussioncomment-19707087) · [Seguimiento de cronología](https://github.com/a2aproject/A2A/discussions/2434#discussioncomment-19870471).
- **Corrida del proyecto.** Fuente [`c7575824b746863a631b7a561b78f4c99a19972f`](https://github.com/argensite/arquia-eval-001/commit/c7575824b746863a631b7a561b78f4c99a19972f). La referencia salió 0 y los siete controles salieron 1 con los testigos esperados. El control de reescritura mantuvo el permiso revocado y los bytes verificables, pero cambió la historia. Los controles de orden conservaron el diario de referencia y fallaron con compromiso del publicador, faltante o posterior al ingreso. El ejecutor general del proyecto salió 0. [Instrucciones, entorno, trazas y logs fijados en `85bcd0f…`](https://github.com/argensite/arquia-eval-001/tree/85bcd0f3e591fa455f4bb4f2a274ac191f254f28/experiments/brennan/evidence) · [Nueva corrida del proyecto desde copia limpia](resultados/brennan.json).
- **Repetición reportada por Brennan.** En A2A confirma haber clonado `c7575824` y ejecutado la instrucción de reproducción desde la raíz con Python 3.12.3 y árbol limpio. Reporta 8/8 coincidencias y retorna 0 para referencia y 1 para los siete controles. El comentario documenta resultados por escenario. No adjunta stdout/stderr originales, hashes de esos archivos ni un entorno completo. El proyecto reprodujo la matriz, y el post externo es verificable como fuente; la ejecución concreta de Brennan permanece como **corrida externa reportada** bajo el criterio de artefactos crudos de este registro. [Informe original del 26 de noviembre](https://github.com/a2aproject/A2A/discussions/2434#discussioncomment-19921374).
- **Límite.** El archivo observador y el ingreso del recibo están controlados por el fixture. La cronología se comprueba condicionalmente a esa observación. Una prueba fuera del simulador necesita un compromiso del digest en custodia independiente antes del ingreso y una observación comparable de ese ingreso. La integridad de bytes y el orden del registro no permiten fijar el momento de un efecto que nadie observó.

**English summary.** Brennan contributed two design failures and reported rerunning all eight scenarios on a clean checkout with Python 3.12.3. The project reran the public fixture on its own infrastructure. The reported external run has a public original comment and a corroborated scenario matrix. External raw outputs and environmental details sufficient to apply the stronger artifact standard remain missing. The simulated observer establishes the ordering rule within the fixture. An actual chronology claim would need independently held commitments and independently comparable receipt-ingress observation.
