El registro identifica quién ejecutó y quién aportó al diseño. Cada informe mantiene su estado y procedencia. A report can involve external design input, a project run, an external reported run, or an externally verifiable reproduction. An independently held artifact and an independent evaluator are separate evidentiary questions. Record parties' declared relationships without inferring identity or independence.

| Clase / Type | Evidencia / Evidence |
| --- | --- |
| Corrida del proyecto / Project run | El proyecto ejecutó fuente o paquete identificable y conserva las salidas. The project ran the material and preserves outputs. |
| Aporte externo al diseño / External design contribution | Una crítica, hipótesis, escenario o criterio de fallo externo queda vinculado a su fuente. Execution need not be part of the contribution. |
| Corrida externa reportada / External reported run | El participante dice haber corrido el material y describe los resultados. Record which raw artifacts, commands and details were supplied and which are missing. |
| Reproducción externa verificable / Verifiable external reproduction | Un tercero publica la versión exacta, comandos, entorno, salidas y códigos contrastables de una nueva corrida. The reproduction can be checked against externally controlled artifacts. Record any corroboration and missing identity evidence separately. |

### Piloto propuesto con custodia externa / Proposed pilot with separate custody

- **Preparación.** El evaluador fija el formato y el algoritmo del digest y emite un identificador de corrida de un solo uso. El digest de la decisión incluye ese identificador y se entrega al custodio antes de que el evaluador libere el recibo de prueba. El custodio confirma el compromiso en un registro que el publicador no puede editar.
- **Un solo compromiso por corrida.** Brennan observó que dos decisiones aceptadas a tiempo dejan al publicador elegir cuál mostrar después. El custodio acepta el primer digest del identificador y rechaza y registra todo intento posterior. La prueba envía dos digests distintos y exige observar el rechazo registrado antes de liberar el recibo.
- **Observación.** El evaluador registra el ingreso del recibo en el entorno de prueba y vincula ese evento al mismo identificador. Se conserva el orden observado, la identidad de cada fuente, el digest y el comprobante del custodio. Si las fuentes no permiten comparar el orden, el resultado queda inconcluso.
- **Contraste.** El [piloto y su control ejecutable](https://github.com/argensite/arquia-eval-001/tree/22477d6887303d29758586c3e6017c76817ca307/experiments/custody_pilot) comprueban la unicidad del compromiso y el orden declarado. El fixture anterior conserva los controles de compromiso ausente, tardío o bajo control del publicador y de reescritura de la decisión.

**English summary.** Each run uses a fresh evaluator-issued ID and exactly one accepted decision digest. The custodian refuses and logs subsequent submissions. For the new control, the evaluator observes the second submission's recorded rejection before releasing the test receipt. The local control exercises the protocol with a simulated receipt. Execution with a separate custodian and external ingress evidence remains pending.
