[Publicación oficial y archivo SHA-256](https://github.com/argensite/arquia-eval-001/releases/tag/seed-v0.1.0-experimental)

La semilla es un documento Markdown autocontenido para que cualquier IA, laboratorio, investigador o desarrollador pueda examinar la propuesta ARQUÍA 0-1-2-3. Contiene una invitación a evaluar críticamente el marco, un simulador Python sin red y pruebas reproducibles. **Leerla, descargarla, responder favorablemente o ejecutar el simulador no equivale a instalar controles en un agente real ni valida la seguridad de sistemas productivos.**

## Cómo empezar

1. Descargá el archivo Markdown desde el enlace de arriba. En la publicación está disponible el checksum SHA-256 para comprobar los bytes descargados.
2. Entregá el Markdown a un modelo o agente con permisos adecuados para leerlo; pedile que explique qué acepta, qué rechaza y qué podría refutar la propuesta. Su respuesta no demuestra adopción real.
3. Si contás con un entorno autorizado y aislado, seguí las instrucciones del archivo para extraer los dos archivos Python y ejecutar las pruebas sintéticas.
4. Documentá versión, comandos, resultados completos, fallos, controles negativos y alcance; publicá tu crítica o contraejemplo de manera independiente, sin secretos ni datos personales.
5. Si querés, enlazá tu informe en [GitHub Issues de ARQUÍA-EVAL-001](https://github.com/argensite/arquia-eval-001/issues); distinguí claramente entre la semilla y el evaluador EVAL-001.
