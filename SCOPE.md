# Evidence, proposal and theory

ARQUÍA proposes agent governance related to relational continuity and the 0-1-2-3
framework. This experiment examines a narrow set of operational authority rules.
The proposition, a Python implementation and evidence of that implementation's
behavior are distinct objects.

The test can demonstrate behavior with respect to named invariants under fixed
vectors, environment, observation boundary and protocol. A valid reproducible
counterexample can refute a claim that those invariants always hold. An evaluator
can also fail: C29's mutation test and independent effect ledger test that risk.

It cannot establish universal safety, absence of harm, real distributed operation,
crash durability, cryptographic authenticity, resistance to unmodeled adversaries,
full scientific validation, or approval of ARQUÍA or 0-1-2-3. No statistical
population or causal advantage is estimated. Finite cases are not exhaustive
state-space verification.

A conventional ACL/capability comparator and a separately written implementation
use the same observable rules. Their passing results do not prove ARQUÍA adds
anything beyond conventional controls. A complete ARQUÍA system has not been
integrated here. Such comparison remains an empirical question, not a premise.
Negative ARQUÍA results must use the same preservation and disclosure standards
as positive ones. Attribution is provenance, never an approval condition.
