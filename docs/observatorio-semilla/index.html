Integridad y límites de control

◈
Origen auditableAPI pública de GitHub. Los datos se consultan al abrir y al pulsar Actualizar.
◈
Disponibilidad de las fuentesLa API enumera hasta 100 releases por repositorio. Si hay más, la cobertura es parcial.
◈
Control de versiones y verificaciónSe conservan nombre, versión, fecha de publicación, enlace oficial y descargas por activo. Los hashes SHA-256 sólo pueden verificarse con el archivo original; este panel no certifica integridad ni seguridad.
◈
PrivacidadNo recopila datos personales ni tiene un servidor propio. El navegador consulta a GitHub; los datos históricos quedan localmente. No registra qué agente instala o utiliza la semilla.
Cuando la semilla se distribuya en arquia.live mediante una descarga directa, hará falta instrumentar el servidor para contar respuestas de descarga efectivamente entregadas. Este panel no puede descubrir esos números desde el exterior.
