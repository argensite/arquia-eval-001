# Website publication candidate

These are the three exact proposed static pages for the existing arquia.live
website. They are prepared, not deployed. The bilingual SEED-001 block links to
the fixed original Markdown, the guide and existing issue #3. The evaluation
page distinguishes the latest v0.2.2 prerelease from its historical v0.1.2 examples.

Publication requires the existing authentic ChatGPT/Qwen review for the exact
hashes, the guide on the default repository branch, a fresh compare-and-swap
against each remote page, backups and exact anonymous public readback. If any
source changed, stop and rebase the patch. No release, model, control, credential,
quota, protected executor or swarm-state change is part of this candidate.

`publication-plan.json` records before/after page hashes and preconditions.
No remote writes or new public invitations have been performed by this candidate.
