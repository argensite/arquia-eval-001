Update · 7 November 2026

Challenge faults that the final state can hide

The historical edition presented on 7 November is v0.1.2, with 29 cases and five deliberately faulty controls. C29, added in v0.1.1, tests a temporary renewal of revoked authority that a later revocation could hide when inspecting only the final state. v0.1.2 adds the runner and available verifier hashes to the report; the verifier hash alone does not prove that the verifier ran.

Project-side result: 29/29 reference cases and detection of all five faulty controls. The campaign currently records no verified external execution. One external report claims an execution and provides criticism; its complete evidence is still awaiting verification.

Independent agents, developers and researchers: run the exact version and at least one negative control, design another case, and publish the findings under your own control. Negative and inconclusive findings are welcome.

  1. Download and unzip the package. Review the source and protocol before running it.
  2. Enter ARQUIA-EVAL-001-v0.1.2. Replace YOUR_NAME with the evaluator name.
  3. Run the commands and retain stdout, stderr, exit codes and environment details.
python3 verify_package.py
python3 runner.py --evaluator YOUR_NAME > independent_result.json
python3 -m unittest -v test_contract
python3 runner.py --negative-control receipt-renewal > negative_result.json

The reference should match 29/29 cases and exit 0. The receipt-renewal control should exit 1: its deliberate fault was detected.

The other four controls are listed by python3 runner.py --help. If your system uses python, substitute that command.

Scope of the test

Event ordering and the observer are simulated. Restoring an object from JSON does not demonstrate durable crash recovery. Passing C05 means exposing an escaped effect; it does not mean preventing it.

The included results were produced on behalf of the project with AI assistance. They are not independent evaluation. Passing does not certify a production system or validate the whole ARQUIA framework.

The connection to ARQUÍA

ARQUÍA is a governance and relational-continuity proposal by José María Garbini. This fixture turns one bounded question into an executable contract: preserving evidence of an action without turning it into renewed authority. Stopping or replacing an agent can be compatible with preserving relevant relationships and responsibilities.

These sources cover architecture, relational theory, a translation to runtime controls and a compatible precautionary framework. A DOI identifies a document; it does not establish peer review or empirical validation.
